## 3. Rejections, re-derived independently

A probe written by the verifier (not the sprint's tests) mutated the seed frame and asserted the
returned code:

```
baseline (unmodified seed)  ok=True   []
drop PAY_3                  ok=False  ['missing_column']
add column FOO              ok=False  ['extra_column']
permute LIMIT_BAL/ID order  ok=False  ['column_order']
target=2                    ok=False  ['invalid_target_value']
EDUCATION=9                 ok=False  ['unsupported_code']
PAY_AMT1=-1                 ok=False  ['out_of_range']
AGE=200                     ok=False  ['out_of_range']
NaN in BILL_AMT2            ok=False  ['missing_value']
empty payload               ok=False  ['empty_file']
```

Negative `BILL_AMT1 = -500` is **accepted**, which is correct: the source data carries credit
balances below zero and the contract documents them as signed. Error messages name the offending
column and never echo a data value, so the validator does not leak rows.

## 4. Single-record validator

`validate_features` raises `ValidationError('out_of_range')` / `('unsupported_code')` for a bad
record and returns the coerced 23-feature mapping for a good one — the surface S5/S7 will call.

## 5. Quarantine


write. `data/quarantine/` is git-ignored; no upload was left in the tree.

## Findings

- **F-1 (owner act, pre-existing).** `scripts/check_no_secrets.py` fails: `docs/acceptance/S01.md`
  contains the operator's real `INITIAL_ADMIN_PASSWORD` and `INITIAL_USER_PASSWORD` values, so they are
  in this repo's history. The repository has no remote, so the exposure is local to this host, but the
  credentials should be **rotated before the S13 deployment**, and the S1 record redacted in a follow-up
  commit. This gate did not edit the S1 record or rewrite history.
- **F-2 (advisory).** `validate_dataframe` and `validate_csv_bytes` share one header checker; a
  malformed frame that also renames a column reports `missing_column` before `duplicate_column`. The
  first failure is the right one to surface, so this is ordering, not a defect.
- **F-3 (advisory).** Deviations D9–D11 are recorded in `docs/architecture.md`; D9 (hard bounds in the
  validator vs the narrower documented UI bands) is intentional and does not affect the S2 clause.
