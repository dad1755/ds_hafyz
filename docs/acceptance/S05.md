Notes on how the sweep was done: each cutoff was probed at the value itself and at the immediately
adjacent float (`math.nextafter`) on both sides, so the half-open edges are tested at the only
values where an off-by-one in the comparison can show; the 10,001-point sweep additionally asserts

rows were produced by driving `InferenceService` with a stub pipeline that returns a fixed
probability, so the `>= 0.5` rule is exercised without needing a real row to land exactly on 0.5.
