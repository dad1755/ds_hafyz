# 5. Objectives

Draft, Sprint 14. Each objective is stated so that it can be checked against a file or a command,
and the "how it is checked" column names that file. Objectives that the project did not meet are
marked as not met rather than quietly reworded.

| # | Objective | How it is checked | Status |
|---:|---|---|---|
| O1 | Use a real, cited, public dataset without altering it | `evidence/s0/inspect_dataset.txt` records 30,000 × 25 and SHA-256 `a0f0ab49…176ca1`; `docs/data_dictionary.md` states the seed is immutable | met |
| O2 | Validate and preprocess the data with a documented, leakage-free contract | `docs/preprocessing_contract.md`; the scaler-fitted-on-train check in `models/metrics.json` (`max_abs_delta_vs_train_mean` 0.0) | met |
| O3 | Produce exploratory analysis with real figures and interpretations | six figures under `models/eda/` regenerated byte-for-byte by `ml/generate_eda.py`; captions in `docs/report_evidence.md` §6.3 | met |
| O4 | Train and compare at least three classifiers | three pipelines in `models/metrics.json`; cross-validated ranking and held-out comparison | met |
| O5 | Evaluate on an independent held-out set with accuracy, precision, recall, F1, ROC-AUC and confusion matrices | `models/metrics.json` `evaluation` block; six-figure arithmetic check with `max_abs_delta` 0.0 | met |
| O6 | Justify the selected model on a stated rule, not on accuracy | `models/metrics.json` `selection.rule` and `selection.objective`; the held-out set played no part | met |
| O7 | Serve the model behind a real application with Admin and User roles | `src/security.py`, `src/accounts.py`, `src/pages_admin.py`, `src/pages_prediction.py`; T01–T04, T07, T12 in `docs/test_matrix.md` | met |
| O8 | Give the user a prediction, a probability, a band and advice | `evidence/s7/ui_vs_pipeline.txt`; the result panel equals the pipeline bit-for-bit | met |
| O9 | Give the administrator user management and dataset management | `evidence/s8/audit_probe.txt`, `evidence/s9/probe_datasets.txt` | met |
| O10 | Test the system, including adversarial cases, and record the output | `docs/test_matrix.md`; 285 tests in `evidence/s11/test-results/pytest_all_verbose.txt` | met |
| O11 | Deploy the system publicly over HTTPS without exposing an origin port | `evidence/s13/browser_check.txt`, `evidence/s13/smoke_test.txt`, `docs/deployment.md` §10 | met |
| O12 | State the limitations and the ethical position honestly | §20, §22 of this report; `docs/architecture.md` §7 | met |
| O13 | Achieve default-class recall above 0.60 | measured recall is 0.3557 at threshold 0.5 (`models/metrics.json`) | **not met** — reported as the central limitation (§22.1) |
| O14 | Audit the model for demographic fairness | no fairness audit was run; `SEX`, `EDUCATION`, `MARRIAGE` and `AGE` remain model inputs | **not met** — named as future work (§23.3) |
| O15 | Confirm the group's own plan (schedule, members, contribution split) | only the group can confirm it; no record exists in this repository | **unconfirmed** — see §21.3 and `docs/rubric_matrix.md` B8 |

O13 deserves emphasis rather than burial. It was an objective, the delivered model does not meet
it, and the report says so with the measured number. O14 and O15 are the same kind of statement:
an honest gap is worth more than a claim a reader cannot check.
