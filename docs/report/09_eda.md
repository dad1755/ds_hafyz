# 9. Exploratory Data Analysis

Draft, Sprint 14. The six figures were generated by `ml/generate_eda.py` from the CSV alone; every
number in a caption is read from `models/eda/summary.json`, and the captions below are the ones
the report must use. Full interpretations with the same numbers are in
`docs/report_evidence.md` §6.

## 9.1 How the analysis was produced

`ml/generate_eda.py --csv data/UCI_Credit_Card.csv --out models/eda` writes six PNGs and a JSON
summary. Two independent runs produce byte-identical files (`evidence/s3/eda_determinism.txt`), and
all six decode from disk in a fresh container (`evidence/s3/eda_render_after_restart.txt`). No
figure in this section is a placeholder or an image lifted from an earlier draft: the draft's
embedded charts were never reused.

## 9.2 The figures and what they show

**(a) Target distribution — F1.** 23,364 accounts (77.88%) did not default; 6,636 (22.12%) did.
Every later evaluation decision follows from this one: a constant "no default" answer already
scores 77.88% accuracy, so accuracy cannot be the criterion for choosing a model.

**(b) Age by class — F2.** Mean age is 35.42 years for class 0 and 35.73 for class 1, a
difference of 0.31 years; medians are 34 for both. Age carries almost no univariate signal here,
which is worth stating because the earlier draft implied demographic separation that the data does
not show.

**(c) Credit limit by class — F3.** Class 0 has median 150,000 NTD (mean 178,099.73); class 1 has
median 90,000 NTD (mean 130,109.66). Lower-limit accounts default more often in this sample. The
distributions overlap heavily, so a limit alone cannot classify an account.

**(d) Default rate by `PAY_0` — F4.** This is the strongest single relationship in the data:

| `PAY_0` | n | share | default rate |
|---:|---:|---:|---:|
| −2 | 2,759 | 9.20% | 13.23% |
| −1 | 5,686 | 18.95% | 16.78% |
| 0 | 14,737 | 49.12% | 12.81% |
| 1 | 3,688 | 12.29% | 33.95% |
| 2 | 2,667 | 8.89% | 69.14% |
| 3 | 322 | 1.07% | 75.78% |

The rate rises steeply once the account is one month late and is above 69% at two months late.
This is why `PAY_0` dominates the fitted tree's importance (68.01%, §12.4) — the model is largely
learning a relationship a human reviewer already knows, which is a fair criticism of the modelling
ambition and is discussed in §19.

**(e) Default rate by `EDUCATION` — F5.** Code 1: 19.23% (n = 10,585); code 2: 23.73%
(n = 14,030); code 3: 25.16% (n = 4,917); code 4: 5.69% (n = 123); code 5: 6.43% (n = 280); code 6:
15.69% (n = 51); code 0: 0.00% (n = 14). The four small codes together (0, 4, 5, 6) are 468
accounts at 7.05%. The non-monotone shape is the evidence behind §8.4's warning that treating
these codes as a single number is a modelling compromise. The earlier draft reported "others" as
5.7%, which was code 4 alone; the corrected aggregate is 7.05% with its sample size (E2).

**(f) Correlation heatmap — F6.** The 13 amount columns are strongly correlated within their
blocks: `BILL_AMT1`–`BILL_AMT2` r = 0.9515, `BILL_AMT5`–`BILL_AMT6` r = 0.9462,
`BILL_AMT4`–`BILL_AMT5` r = 0.9401. This is expected — successive monthly balances of the same
account — and it means the six balance columns carry substantially redundant information. It also
argues against reading a linear model's coefficients as independent effects.

## 9.3 What the EDA does not show

- No causal claim: the figures describe association in a 2005 sample.
- No time dimension: the dataset is a snapshot of six billing months, not a series, so no trend
  analysis is possible.
- No fairness analysis: `SEX`, `MARRIAGE` and `EDUCATION` differences are descriptive only and are
  not corrected for confounding (§20.3).
- No outlier analysis beyond the descriptive ranges: the tails are reported, not trimmed.
